# Veneel Kumar A. — AI Engineer Portfolio

A React + Vite portfolio inspired by the supplied AI-engineer Figma reference. It uses plain CSS for the visual system and a lightweight React canvas network background, keeping the stack easy to explain in interviews.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```

## Deploy

This is a static Vite site. It can be deployed to Vercel, Netlify, GitHub Pages, or any static host. The included CV and profile image live in `public/assets`.

## Main stack

- React
- Vite
- CSS
- Lucide React
- HTML Canvas for the animated network background
